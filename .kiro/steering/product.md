# Product Overview

School Management System — a full-stack web application for managing private school operations.

## Core Domains

- **Students**: Registration, profiles, group enrollment, attendance tracking
- **Teachers**: Profiles, subject assignments, session management
- **Groups & Group Types**: Class groupings with configurable types and levels
- **Sessions & Series**: Scheduling (calendar-based), recurring session series
- **Payments**: Student payment tracking, payment details, pricing rules, admin management
- **Attendance**: Per-session attendance recording
- **Rooms, Levels, Subjects, Pricing**: Reference/configuration entities
- **Catch-ups, Discounts, Transfers**: Supplementary payment/scheduling features

## Key Characteristics

- Multi-language support (i18n via ngx-translate)
- Image upload for student/teacher photos
- PDF generation for reports/receipts
- Calendar view for session scheduling (FullCalendar)
- Admin payment management panel
